# NORTE — Cartography & Adventure

**Find your direction. Explore beyond.**

NORTE is an outdoor adventure and cartography storefront concept created for explorers, hikers, travelers, and outdoor enthusiasts. It brings together navigation essentials, trail maps, exploration tools, and carefully selected adventure accessories in one refined digital experience.

Designed around the spirit of discovery, NORTE combines the timeless character of traditional cartography with the practical needs of modern exploration.

---

## Our Philosophy

Every journey begins with a direction.

At NORTE, we believe that preparation makes exploration more meaningful. Whether planning a mountain expedition, navigating a forest trail, discovering a new destination, or organizing a weekend escape, the right tools can help make every adventure more enjoyable.

Our concept focuses on functionality, thoughtful design, and a lasting connection with the outdoors.

**Our mission:** Inspire confident exploration through useful navigation tools, outdoor essentials, and a carefully curated shopping experience.

## Run Locally

If the storefront loads its product catalog through JavaScript `fetch()`, run it using a local web server rather than opening `index.html` directly.

With Python installed, open a terminal in the project directory and run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy with GitHub Pages

1. Upload the complete storefront files to the root of the `norte-adventure` repository.
2. Open the repository's **Settings** page.
3. Select **Pages** under the Code and automation section.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` directory.
6. Save the configuration and wait for deployment.

The published address will typically follow this format:

`https://YOUR-USERNAME.github.io/norte-adventure/`

Replace `YOUR-USERNAME` with the actual GitHub account name.
